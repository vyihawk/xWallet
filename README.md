# Альфа-Банк × Азбука вкуса — прототип акции

Кликабельный мобильный сценарий программы повышенного кэшбэка: от первого оффера до зачисления на бонусный счёт 10-го числа.

## Запуск

Откройте [index.html](index.html) в браузере. Сборка и установка зависимостей не нужны.

## Путь клиента

1. Оффер на главной странице банка.
2. Лендинг акции.
3. Каталог акционных товаров.
4. Объяснение механики.
5. Согласие на использование данных чека.
6. Подтверждение участия.
7. Покупка появляется в истории.
8. Детали чека и ожидаемый кэшбэк.
9. Уведомление о фактическом начислении 10-го числа.
10. Раздел кэшбэка со статистикой.

Этапы можно листать кнопками «Назад» и «Дальше», выбирать напрямую в списке или переходить по кнопкам внутри экрана. Каталог, фильтры истории, избранное и раскрывающиеся условия кликабельны.

## Публикация через GitHub Pages

Сайт публикуется из корня ветки `prototype/alfa-loyalty`. Адрес: https://vyihawk.github.io/xWallet/.

Все данные покупок, начислений и дат в прототипе демонстрационные. Это не подключено к банковским системам и не проводит реальные платежи.
